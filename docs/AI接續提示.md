# 可貼給另一台電腦 AI 助手的提示

```text
請先讀取這個 repo 的 AGENTS.md、README.md、docs/SOP.md。
協助我使用磨課師或公務園研習；先查本機學習紀錄，核對帳號、年度、課程與通過標準。
使用共享 ai-browser-launch 取得占用，固定同一實例和精確分頁。每段操作前續約，先登記工作 PID，finally 斷線並釋放。
平台登入由我自行完成；不複製別台瀏覽器 profile 或登入憑證。
請建立 local/course.json，填入你在現場核對的值與我指定的最晚停止時間。
播放時只能啟動剛載入起點的影片，自然播完後才按下一部。估算只安排檢查，不快轉、不改速、不假裝活躍。
若我要求設定計時，建立本機定時任務，每分鐘先讀 state 與 nextCheckAt。到點用 watch 密集核對；ready_to_advance 後再用 advance 重新核對現場並切章。
例行喚醒保持安靜；只有需要我處理、出錯或完成才通知。
閒置提示先通知我；要求本人在場、出席、簽到或作答時請停止，由我處理。普通提示是否授權你等待30秒後按一次，須依我本次指示。
正式測驗由我自行作答與繳交；完成後你可以核對成績與通過狀態、協助理解已公布錯題。
一般問卷依我指定偏好及送出授權處理，不覆蓋我已填的答案。
通過後下載原始證明並核對姓名、課名、認證時數與日期。時數傳報、學校回傳及審核分別確認，不推定已入帳。
```

提示中時間、課名、帳號與普通提示授權刻意未預填，由每次任務確認。
