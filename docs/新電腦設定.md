# 新電腦設定與接續

1. Clone repo、`npm ci`，執行語法檢查及測試。
2. 確認共享啟動器和 Chrome。已有 ai-browser-launch 的電腦沿用原配置；全新機器用 scripts/install-browser.ps1 建立獨立且受占用管理的 profile。
3. 登入 GitHub 的同一帳號以讀取私人 repo；GitHub 登入不等於研習平台登入。
4. 用啟動器開啟平台，在這台電腦自行登入並核對身分。必要的驗證碼／憑證由使用者輸入。
5. 重新查看我修的課或學習紀錄，確認已通過、進行中與未報名。上一台電腦的紀錄不是當前狀態。
6. 取得本機精確分頁 ID，設定課程完整網址、可見課名、帳號標示、影片清單及最晚停止時間。不可複製別台 targetId 或 LeaseId。
7. 公務園須讀取所有框架，尤其 s_dialog 提醒；不可保存框架帶憑證的 URL。
8. 先 observe 核對，再按需求 start／watch／advance。不要拿真實研習頁跑假完成測試。
9. 定時任務需在新電腦重新建立。提示處理必須保留本次授權；不把原電腦授權或安靜等待當成本人在場。
10. 證書存本機 certificates/ 或案件資料夾，核對姓名、時數與日期。回傳學校前重新核對當年度通知與登入帳號。

若顯示分頁不存在：重新觀察這台電腦的頁籤後設定新 targetId，建立新狀態檔。若 .lock 留存：先核對鎖內 PID 的程序已退出，再由使用者移除；不自動搶占。

`TRAINING_PWSH` 可指定 PowerShell 7 執行檔完整路徑。工具目前只支援 Windows 的共享啟動器；Node 邏輯可在 CI 驗證，不代表 macOS／Linux 的瀏覽器占用已支援。
