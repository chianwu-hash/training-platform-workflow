# 資料保護

GitHub 僅保存通用程式、設定範本、SOP、測試與去識別的經驗。私人 repo 仍不應存放帳號、登入憑證或正式證明。

不要提交：

- local/ 設定中的姓名、帳號、分頁 ID、最晚停止時間。
- runtime/ 進度、提示紀錄、占用狀態與鎖檔。
- Chrome profile、Cookie、session、token、密碼、PIN、驗證碼。
- certificates/、downloads/、screenshots/ 的證書、個資與學校填報佐證。
- 學校通知本文、校內表單與郵件連結。

分享操作問題時先刪除個資與框架網址中的登入憑證。公開範例只填占位值。新電腦以平台學習紀錄確認完成狀態，不同步 Chrome profiles。
