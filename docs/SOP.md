# 線上研習雙平台操作SOP

更新日期：2026-10-10｜適用對象：使用者與已獲授權的 AI 助手。

依據：2026-10-09 至 2026-10-10於「edu磨課師」及「e等公務園+／衛生福利e學園」的實際操作、平台可見通過紀錄、證書及學校表單回傳紀錄。平台改版、不同課程條件及未實際出現的提示，均須重新核對；本文件不保證所有課程介面相同。

## 1. 接手前先確認

1. 先讀本案 `00_檔案索引.md` 與 `近兩年必要線上研習清單.md`，核對研習年度、類別、要求時數、期限及學校回傳方式。
2. 查看平台既有學習紀錄，辨識已通過、進行中、尚未報名。不要重複修課或重複送學校表單。
3. 核對可見登入姓名、課程代碼、完整課名、開課期間、身分限制及通過標準。歷史未完成名單只代表該次統計，不能直接推定現在仍未完成。
4. 由使用者自行登入。登入失效後停止操作並通知；使用者重新登入後，再核對帳號、課程及目前章節。
5. 若使用者要求依序播放，接手內容包含：開啟第一個待播放章節、核對影片確實播放、設定監看、依自然播完證據切換下一部，以及完成後通知。不能只開影片便宣稱已設定計時。

### 操作分工

| 步驟 | AI可協助事項 | 由使用者完成／判斷 |
|---|---|---|
| 選課、報名 | 核對需求、資格及通過標準，依指示報名 | 資料不足或資格不符時確認選課 |
| 影片 | 按可見播放鍵、唯讀監看、自然播完後切章 | 實際學習；手動暫停後決定何時恢復 |
| 一般閒置提示 | 依第5節的既有授權處理 | 需要本人在場、出席或簽到聲明時自行操作 |
| 測驗 | 找到入口、說明概念、繳交後協助理解錯題 | 正式認證測驗的選答與繳交 |
| 問卷 | 依使用者明確偏好填寫、核對並送出一般課程回饋 | 個人經驗、實質承諾或未授權的主觀內容 |
| 證書、學校填報 | 下載、核對、整理證明；依授權填報 | 資料疑義及正式紀錄未確定處的確認 |

## 2. 共用瀏覽器規則

- 使用註冊的AI工作瀏覽器。每次任務依 `ai-work-browser` 技能取得分配，固定該實例及精確分頁，不自行換瀏覽器。
- 每次接手取得新的占用與LeaseId，使用回傳CdpUrl；忙碌時等候或略過，不借用其他占用中的實例。
- 每段瀏覽器操作前續約，持續操作時至少每60秒續約。長時間工作程式須依技能登記PID。
- 連線結束先斷線、停止自有工作程式，再於 `finally` 釋放占用。等待使用者登入或處理必要確認時，也應結束連線並釋放。
- 不快轉、不改速、不修改時數、不刷新來規避提示、不用滑鼠鍵盤假裝活躍、不注入活動事件。
- 例行監看只讀取；不為維持活躍移動滑鼠。不要在輪詢中反覆列出所有分頁或擷取截圖。
- 不輸出含登入token的框架網址、Cookie或敏感資料。多帳戶服務寫入前，重新核對可見帳號。

## 3. edu磨課師流程

入口：<https://moocs.moe.edu.tw/moocs/>

1. 登入後由「個人資料」核對真實姓名、電子郵件、學校及身分。頂端遮罩姓名不足以確認帳號；不得為報名擅自變更身分。
2. 進入「我修的課」，查看目前修課狀態、閱讀時間、成績與學習證明。
3. 在課程詳細頁核對開課期間、認證時數、資格及「通過標準」。不同課程的閱讀時間與及格分數不同，不能沿用上一門。
4. 尚未報名時按「立即報名」；已報名時按「已報名（前往學習環境）」。進入後核對課程代碼與名稱。
5. 展開章節並選擇影片。側欄可能同時出現同名影片與測驗：測驗列可能含「100pt」「未測驗」，必須辨識影片列，不能只按下一個項目。
6. 新載入影片若停在起點，按可見「播放」控制，實讀 `paused=false`，再確認 `currentTime` 前進。需要操作時可將精確分頁帶到前景。
7. 依第4節監看。上一部自然播完後，按完整下一影片名稱；重新核對章節、影片來源與長度，再決定是否需要按播放。
8. 影片完成後檢查「通過標準」「作業」「課程回饋」及測驗項目；依第6、7節處理。
9. 回到「我修的課」，確認課程顯示「通過」，再開啟「學習證明」取得證書。

**閒置注意：** 本案看過固定說明「如閒置超過30分鐘，將自動導向首頁，並扣除此30分鐘學習紀錄。」這是固定警語，不是新彈窗，不可預先點擊。磨課師實際閒置彈窗的按鈕與處置尚未在本案完整驗證，遇到時須現場讀取，不能套用公務園的「確定」按鈕。

## 4. 影片監看與下一部播放

### 啟動與記錄

1. 首次讀取實際章節、`currentSrc`、`currentTime`、`duration`、`paused`、`ended`及所有框架中的提示。
2. 只有「剛載入、尚未播放、停在起點」的影片可按播放。已播放過的暫停影片不得自行恢復。
3. 記錄首次確認播放時間；若起始時間由影片進度倒推，標示為估算，不寫成實際觀察。
4. 使用被動 `ended` 事件觀察器，不能自行觸發事件或改影片狀態。
5. 將監看狀態寫入本案 `暫存區/製作中/`，建立或更新實際自動化，確認啟用狀態、課程、固定分頁、下次檢查時間及最晚停止時間後，才回報已安排。

### 檢查時機

- 一般播放期間，每分鐘喚醒僅讀本地狀態與時間。尚未到 `nextCheckAt` 時，不取得瀏覽器占用，也不讀網頁。
- 依最新實讀進度估算檢查點：影片結尾前約90秒；長影片播放到25分鐘前約90秒；公務園上次實際閒置確認後25分鐘前約90秒。採最早且仍適用的時間。
- 尚無新週期確認紀錄時，可用重新登入後開課時間安排提示檢查，但不能把重新登入時間寫成「已確認閒置提示」。磨課師30分鐘警語另列檢查，不推定與公務園25分鐘週期相同。
- 到點後保留有效占用，每5秒唯讀檢查影片、所有框架與提醒。短等待不超過10秒；至少每60秒續約。
- 使用者要求精準檢查25分鐘時，以實讀進度安排25:00前約5秒、25:00及之後每5秒讀取；自約23:30開始監看到25:30或提示出現。暫停或緩衝時依真實進度重新估算。
- 估算時間只安排讀取，不能當作播完或提示已出現的證據。平台閒置計時也不保證恰好等於影片25:00。

### 唯一允許的切章依據

符合以下任一條件，並核對目前可見章節後，才能切換：

```text
ended = true 且 currentTime >= duration - 0.2
或
被動取得的endEvidence.src = 目前currentSrc
且 endEvidence.time >= duration - 0.2
```

同一筆結束紀錄只能處理一次。切章後核對新章節、來源與長度；已播放就不要再點播放。進度回退、來源被外部切換、章節不符，先停止並釐清，不能猜測跳章。

### 每次檢查後保存

狀態至少包含：實讀時間、課程、精確分頁、章節、來源、`currentTime`、`duration`、`paused`、結束證據、已完成章節、已處理結束紀錄、首次播放時間、開課時間、上次實際確認時間、`nextCheckAt`及監看狀態。

後續喚醒優先讀取最新狀態安排檢查；狀態檔不能取代現場結束證據。例行檢查與切章保持安靜，只在需要使用者處理、發生錯誤或全部影片完成時通知。

## 5. e等公務園+／衛生福利e學園流程及閒置處置

課程資訊入口：`https://elearn.hrd.gov.tw/info/<課程代碼>`。衛福學習頁：<https://mohw.elearn.hrd.gov.tw/learn/>；其他開課機關可能使用不同學習網域。

1. 課程資訊頁按「上課去」，核對學習頁框架中的真實姓名及課程。暱稱不足以確認本人帳號。
2. 進入「開始上課」，依序選影片章節。影片與導覽位於不同框架，須一起讀取。
3. 新載入影片停在起點時，將滑鼠移到已觀察到的播放器以顯示控制，再按可見播放鍵。此動作只用於開始播放，不作為例行活躍維持。
4. 依第4節監看；除了標準對話框，也檢查提醒框架。此案提醒出現在 `s_dialog`，只看頂層modal會漏掉。

### 一般閒置提醒的已授權處置

本案實際出現的內容為「閱讀閒置提醒！」、「請點選『確定』即可繼續閱讀」、「未回應將於…秒後自動登出」。可見按鈕是「確定」。

1. 真正出現新提示時先通知使用者，記錄提示內容、精確分頁及通知時間。同一提示不重複通知。
2. 只有使用者明確授權時，通知後等30秒，期間維持有效占用；使用者回覆正在處理或停止，就不點擊。
3. 30秒後重新讀取同一分頁、同一視窗；已消失就不點擊。
4. 若仍是單純繼續學習或一般閒置提示，操作前續約，核對可見文字後按一次「確定／確認／繼續」中實際出現的按鈕。不能盲用舊選擇器。
5. 重新讀頁面確認提示消失與結果，記錄實際處理時間，再估算下一檢查點。沉默30秒不代表使用者確實在場。
6. 若要求聲明本人在場、出席、簽到、作答或其他實質承諾，只通知並停用監看，留使用者自行處理。

未知彈窗、登入失效、首頁、課程不符或分頁關閉：通知一次、停用自動化、斷線釋放。不得自行重新登入或重開課程。使用者重新登入並要求接續時，再重新核對後啟動。

## 6. 測驗與錯題理解

1. 先確認是否有測驗，以及它屬於練習、自我檢測或正式認證考試；依可見通過標準判斷，不能由名稱猜測。
2. 磨課師從課程測驗／作業入口進入；公務園從「測驗／考試」進入，核對課名後選「進行測驗」。考試可能另開分頁，要核對來源分頁與課程。
3. 正式認證測驗由使用者自行選答、核對及繳交。AI可說明相關知識，但不代填答案、不提供待繳交試卷的答案表，也不以「使用者再確認」方式代做或預先判斷哪些答案答錯。
4. 繳交後查看平台「查看結果」或成績頁；由平台公布的結果辨識錯題，再協助理解題意、概念與誤解。未公布正確答案時，不把推論寫成官方答案。
5. 確認實際分數、及格門檻與通過狀態。是否能重考、要不要重考，由平台規則與使用者決定；不能用單次畫面推定已取得時數。

## 7. 課程問卷

1. 磨課師查看「課程回饋」等實際入口；公務園從「問卷／評價」選「填寫問卷」。核對新分頁或框架中的課程與使用者。
2. 先讀全部題目與既有答案。不要覆蓋使用者已填內容；不同課程的選項數值與欄位名稱可能不同。
3. 使用者要求「普通填寫，不用太特別」時，一般滿意度、測驗幫助及平台功能題可選可見的「普通」；文字建議可填「暫無特別建議。」或「無補充意見。」
4. 本案曾依授權選「取得學習認證時數」「單位或上級機關要求閱讀」作為修課原因。新課仍要確認是否符合實際目的，不照抄勾選代碼。
5. 涉及本人經驗、個資、在場／出席聲明或其他實質承諾時，請使用者自行確認。
6. 一般回饋已獲送出授權時，核對答案後按可見繳交按鈕，處理平台的同一送出確認一次。公務園本案曾出現「您確定要繳交嗎？」及「更新完畢。」；仍須讀取新畫面。
7. 以「修改問卷」「已填」或其他實際成功訊息確認，不以點擊成功當作問卷已繳交。學校回傳表單是另一個流程。

## 8. 通過紀錄與證書

### 磨課師

在「我修的課」核對通過、閱讀時間、成績及認證時數，再開「學習證明」。使用平台原始證明與原生下載；必要時讀取平台已開啟的原始PDF資源，不能把網頁列印另製的PDF冒充原始證書。

### 公務園

1. 透過「離開課程」返回資訊頁，核對閱讀時間、測驗成績、問卷狀態與「已通過」。
2. 進入「個人專區」→「學習紀錄（含證書）」→「列印證書」，選正確年度並搜尋。
3. 只勾選目標課程代碼與名稱所在列。「身分證字號完全顯示」維持未勾選，保留遮罩。
4. 按「產生證書」，使用Chrome原生下載。不得改下載行為來繞過瀏覽器設定。

### 共用查核

- 檔案可開啟、PDF格式有效；核對姓名、課名、認證時數及通過日期。姓名若由圖像呈現，必須視覺核對，不能只依文字擷取。
- 保留原始證書；本案證明存 `佐證紀錄/<研習類別>/`。多份合併成一份時保留各原始檔，逐頁核對姓名與時數，輸出穩定檔名。
- 平台顯示「近期傳報」或當日通過，不代表時數已傳報入帳；後續另查實際紀錄。

## 9. 學校表單回傳與收尾

1. 從已核對的學校通知取得正確表單，確認年度、類別、截止日及附件格式；不要只沿用舊連結。
2. 開啟後核對可見Google登入帳號。此案學校帳號為 `本次指定的學校帳號`；若顯示其他帳號，使用「切換帳戶」後再核對。
3. 填姓名、要求的時數／參與狀態及電子郵件記錄選項；透過可見上傳介面附正確證明。多份證明依學校要求先合併。
4. 送出前再次核對帳號、姓名、類別、時數及附件名稱，依已取得授權按一次「提交」。
5. 送出後若導頁造成腳本連線狀態變更，先讀同一分頁確認；不要直接再次提交。
6. 以「我們已經收到您回覆的表單」等實際成功訊息為準，保存回傳成功畫面，更新同一份索引及研習清單。
7. 已送出不等於學校已審核；帳號或資料疑義依使用者確認處理，不能擅自重送。

## 10. 狀態用語與交接檢查

| 狀態 | 必須具備的依據 |
|---|---|
| 播放中 | 實讀未暫停且進度前進 |
| 影片播完 | 每部影片符合自然結束證據，完成清單無遺漏 |
| 課程通過 | 平台顯示通過，必要測驗／問卷等條件符合 |
| 證明取得 | 原始證明已保存，姓名、課名、時數與日期核對 |
| 學校已回傳 | 正確表單實際收到回覆，佐證保存 |
| 時數已傳報／學校已審核 | 對應系統或承辦的另行確認，不能由上述狀態推定 |

交接時留下：平台、課程代碼／名稱、可見帳號、固定實例與分頁、最新實讀狀態、已完成章節、提示處理紀錄、下次檢查時間、最晚停止時間、自動化啟用狀態，以及測驗／問卷／證書／回傳尚待辦事項。

全部影片完成時停止該監看並通知，列出剩餘測驗與問卷。使用者要求停止時立即停用。接續下一門前，先停止上一門的監看，避免兩個流程操作同一實例。

## 11. 本 repo 工具的使用範圍

`src/cli.js` 提供 observe、watch、start、advance。使用 local/course.json 指定完整課程、帳號標示、固定實例、精確分頁、影片章節及最晚停止時間。

- 每台電腦重新設定，不複製舊分頁 ID 或 LeaseId。
- watch 只觀察；ready_to_advance 後由 AI 或使用者呼叫 advance，重新讀取現場證據。
- 出現閒置或其他提示時 CLI 停止，不自動點擊。依第5節處理後重新核對並建立新的狀態檔。
- 程式沒有問卷填寫、正式測驗選答或學校表單提交功能；由已授權 AI 依本 SOP 現場操作。
- 選擇器需要依新版面核對，找不到唯一控制就停止，不能猜測。
